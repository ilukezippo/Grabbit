# Grabbit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Installable, signed Android APK of Grabbit (yt-dlp powered downloader) per the spec.
**Architecture:** Single-module Compose app. Pure-Kotlin logic (format selection, link parsing, cookies, Instagram ids) lives in `core/` and is unit-tested on the JVM; Android glue (engine, services, UI) wraps it.
**Tech Stack:** Kotlin 2.1, AGP 8.13, Compose Material3, youtubedl-android 0.18.1 (library + ffmpeg), OkHttp, AppCompat (per-app locale).
**Spec:** docs/2026-11-23-grabbit-design.md

## Global Constraints
- Package `com.ilukezippo.grabbit`, minSdk 24, targetSdk/compileSdk 35, ABIs arm64-v8a + armeabi-v7a, `useLegacyPackaging = true` (required by youtubedl-android).
- Output folder: `Download/Grabbit`. No ads, no analytics, no server. Cookies stay in app-private storage.
- All strings in `values/strings.xml` and `values-ar/strings.xml`.

## Review Focus
1. Shared text containing words + URL (e.g. "Check this https://…") → URL extracted. (LinkExtractorTest)
2. Video with no height info / single format → "Best" option still offered and selector valid. (FormatSelectorTest)
3. Instagram image-only / carousel post → images saved, not a yt-dlp "no video formats" error. (InstagramIdsTest + IG client fallback)
4. Cancelling a live recording → partial stream kept and saved as playable .ts. (manual)
5. Title with `/ : ? *` or Arabic chars → safe filename. (FileNamesTest)
